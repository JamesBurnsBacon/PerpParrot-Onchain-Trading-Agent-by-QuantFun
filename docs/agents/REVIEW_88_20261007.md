# Local 88-point review rehearsal

The owner requested a risk-rejection threshold of 88 for a hackathon rehearsal.
This experiment keeps the 40-account recent-return control cohort, GPT-6 Sol,
prompt v1.2.0, all other review parameters, and the public-read snapshot fixed.
It changes only `riskRejectThreshold` in the isolated review policy supplied to
the local harness. It does not edit the pinned frozen configuration, scheduled
production policy, order path, or the 15-source maximum.

The input was the saved October 7, 10:23 UTC observation of the recent-return
Top40 (39 traders, one HyperCore vault) selected from the regular-screened
10,987 -> qualified 250 cohort. Each run made fresh Role, Risk and Red-Team
calls with a newly bound policy hash
`0xd77e9a046a401e911033d8ed76db4cbe68b934d60030fbe16422151baafb8116`.
No model result was replayed. All six calls returned HTTP 200 with valid output;
the offline public-read cache had no misses.

| Independent run | Individual candidate checks | Compiled manifest | Sources | Passed hold gate | Source weight / cash |
| --- | ---: | --- | ---: | ---: | --- |
| First | 16/40 | VALID / OK | 12 | 12/12 | 47.12% / 52.88% |
| Repeat | 14/40 | VALID / OK | 11 | 10/11 | 51.01% / 48.99% |

The source sets overlap on ten accounts. The first run retained all seven
sources from the 80-point baseline and added five. All five additions have a
trading or evidence risk score of at least 80: two have path scores 86 and 87
with adverse-price adds in 67% of 94 and 79% of 72 reconstructed adds; one
has concentration risk 83; two have only three and six observed fills,
respectively, with high evidence risk (and one has drawdown risk 83). The repeat
removed two of the first run's sources, added one different source, and that
replacement failed the hold gate. The 12-source result is therefore a valid
single local compilation, not a stable 12-source admission rate or a proven
copy-trading strategy.

The exact source addresses, weights, public trade reads, and model outputs remain
under gitignored `work/screened-cohort-20261007/`. The local file
`strategy-group-r88.md` lists the first compiled group for operator inspection;
it is not a frozen live manifest. No order was placed. The study uses one saved
cohort and mixed-time public reads, so it does not establish forward returns or
production reliability.

To repeat the policy experiment with private input and public-read cache, run
`strict-gate-check.ts` with `--risk-reject-threshold 88`, `--local-dir`, the same
`--inputs`, `--reads`, `--as-of`, and `--offline`. The flag requires an isolated
local database and records the requested threshold in the output report. A new
market snapshot requires fresh reads; a later decision to change production
policy requires its own reviewable integration and freeze.
